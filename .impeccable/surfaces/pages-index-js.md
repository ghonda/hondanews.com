# Home — Honda News

## Escopo e modo

-   Superfície: `pages/index.js`
-   Modo: Experience
-   Público: pessoas interessadas no trabalho profissional de um desenvolvedor de software.
-   Trabalho do visitante: compreender rapidamente a atuação, a forma de pensar e os caminhos para explorar o trabalho.
-   Ação principal: percorrer a abordagem e as frentes de atuação.

## Direção aprovada

-   Mundo: portfólio contemporâneo clássico com clareza de Vercel, refinamento de interação de Linear e composição editorial de Framer.
-   Composição aprovada: `.impeccable/mocks/comp-b-editorial-stack.png`.
-   Momento memorável: o ponto azul que encerra o título se alinha à faixa cobalto que conduz de código a produto.
-   Paleta: off-white, grafite, azul-cobalto e cinza frio.
-   Forma: hero tipográfico editorial seguido por uma faixa de ação e uma seção escura de capacidades.

## Inventário de fidelidade

| Ingrediente visível       | Compromisso composicional                                                                                        | Meio de implementação                      |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Navegação superior        | Palavra-marca à esquerda, três âncoras centrais, contato à direita                                               | HTML semântico + CSS responsivo            |
| Hero editorial            | Título ocupa nove de doze colunas; texto de apoio ancora no terço direito                                        | HTML semântico + CSS Grid                  |
| Pontuação cobalto         | Quadrado azul encerra “contexto.” e alinha com a faixa abaixo                                                    | `span` HTML + CSS                          |
| Faixa de ação             | Campo cobalto em largura total com CTA à esquerda e sequência código → estrutura → interface → produto à direita | HTML + CSS; ticker apenas em telas amplas  |
| Seção “O que eu faço”     | Campo grafite em largura total com três colunas altas e bordas finas                                             | HTML + CSS Grid                            |
| Diagramas das capacidades | Interseção, camadas e interface desenhadas com geometria contável                                                | SVG inline acessível/decorativo            |
| Seção de processo         | Quatro etapas numeradas, ritmo claro e fundo off-white                                                           | HTML + CSS Grid                            |
| Seção de notas            | Índice editorial de três temas, sem fingir artigos publicados                                                    | HTML + CSS                                 |
| Fecho                     | Grande convite para conversa sem inventar e-mail ou disponibilidade                                              | HTML + âncora para o topo                  |
| Movimento                 | Entrada orquestrada do hero, ticker suave e respostas de foco/hover                                              | CSS, com fallback `prefers-reduced-motion` |
| Textura                   | Granulação quase imperceptível, sem virar efeito visual                                                          | CSS; omitida em clientes restritos         |

## Conteúdo e limites

-   Não inventar clientes, cargos, métricas, projetos, depoimentos ou disponibilidade.
-   Não usar fotografias ou identidades de terceiros.
-   Não usar qualquer referência visual ou verbal à fabricante de veículos Honda.
-   As frentes “Produto digital”, “Arquitetura” e “Interfaces” descrevem áreas de prática, não cases comprovados.
-   Links internos devem apontar para seções existentes na própria página.

## Responsividade

-   Em telas estreitas, o título reduz sem perder impacto, a navegação central recolhe e os três painéis tornam-se uma sequência vertical.
-   A faixa azul mantém o CTA e transforma a cadeia de processo em linha compacta com quebra controlada.
-   Alvos interativos mantêm pelo menos 44 px; foco é visível; contraste preserva AA.

## Decisões em aberto

-   Nome civil, biografia completa, links externos, contato real e projetos verificáveis ainda não foram fornecidos.
